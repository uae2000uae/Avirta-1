# Avirta Project Documentation

This directory contains essential documentation for the Avirta project.

## Contents

- **guidelines.md**: General development guidelines for the Avirta project
- **coding_reference.md**: Detailed coding standards and references
- **rule_book.md**: The Junie Rule Book containing mandatory specifications and rules
- **OpenAI_Key.txt**: API key for OpenAI integration (do not share)

## Junie Rule Book

The [Junie Rule Book](rule_book.md) is a central repository for all coding and design specifications that must be consistently applied throughout the Avirta project. It contains rules organized by category and numbered for easy reference.

### When to Use the Rule Book

- When implementing new features to ensure they follow established patterns
- During code reviews to check compliance with project rules
- When making architectural decisions to ensure consistency with existing design principles

### How to Update the Rule Book

The Rule Book should be updated whenever a new specification or rule is established. See the [How to Update This Rule Book](rule_book.md#how-to-update-this-rule-book) section in the Rule Book for detailed instructions.
