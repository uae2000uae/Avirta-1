Avirta Game

Welcome to Avirta!

Avirta is an interactive trivia game where you can test your knowledge across various categories.

How to Start the Game Server

Important: You must start the Flask server before accessing the game!
  1. Make sure you have Flask installed:
    pip install flask
  2. Navigate to the project root directory in your terminal or command prompt
  3. Run the Flask application:
    python app.py
  4. Once the server is running, click the "Access the Game" button below:
Access the Game

This button will only work if the Flask server is running at http://localhost:5000

Game Features

  • Create custom game rooms with up to 5 categories
  • Join existing game rooms
  • Answer trivia questions to earn points
  • Use special tools like Double Points, Change Question, and Steal Question
  • Compete with friends to see who can get the highest score
