How to Play

  1. Create a game room or join an existing one
  2. Select questions from the game board based on category and point value
  3. Answer questions correctly to earn points
  4. Use special tools to gain an advantage:
    • Double Points: Double the points for your next question
    • Change Question: Swap your current question for a new one
    • Steal Question: Take a question from another player
  5. The player with the most points at the end wins!
