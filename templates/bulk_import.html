Templates

Use one of these templates to format your questions correctly:

CSV Template Excel Template
Accepted formats: CSV, Excel (.xlsx, .xls)

Instructions

  1. Download the template file
  2. Fill in the template with your questions
  3. Upload the completed file using the form above
  4. Click "Import Questions" to begin the import process

File Format

Your file should contain the following columns:

  • question (required): The text of the question
  • type (required): The question type (multiple_choice, true_false)
  • category (optional): The category for the question
  • points (optional): The point value (100, 200, 300, 400, 500)
  • options (for multiple choice): Comma-separated list of options
  • correct_answer (required): The correct answer
